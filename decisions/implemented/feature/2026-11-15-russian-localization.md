# Decision: русская локализация (форк whale-girl-ru)

Status: implemented

## Problem

Плагин `whale-girl` (домашний питомец в web-интерфейсе DSH) написан для китайской аудитории: тексты интерфейса питомца, фразы, карточка настроек, метаданные плагина и README — на китайском (частично английском). Русскоязычному пользователю нужен тот же питомец с русским интерфейсом, без переписывания механик и без расхождения с апстримом.

## Decision

Форк [vlln/whale-girl](https://github.com/vlln/whale-girl) → [bondiano/whale-girl-ru](https://github.com/bondiano/whale-girl-ru); переводится только пользовательская поверхность, идентичность плагина сохраняется (`package.json` name `whale-girl`, запись в `cordis.patch.yml`, `NAMESPACE`, `SETTINGS_NAMESPACE` — гейт `verify-config-sync` держит их равенство):

- **client half** (`src/client/index.ts`): aria-подписи, кнопки меню (🍗 Покормить / 🎾 Поиграть / 🎭 Сменить), подсказка одного персонажа, строка статуса (`Задач: N · провалов: M`, `Звание «…»`), маркер офлайна, консольные предупреждения.
- **Карточка настроек** (`src/client/settings-card.ts`): полный словарь `ru` в `ctx.locale.register(SETTINGS_NS, { zh, en, ru })` — базовые `zh`/`en` сохранены (контракт локали требует оба), русский добавляется как дополнительный; активный язык хоста `ru` берёт его.
- **Node half**: звания (`src/core/pet-state.ts`), записи воспоминаний (выполнение/провал/новая сессия/возврат/уровень), встроенные пулы фраз (`src/core/config.ts` + фолбэк `src/core/interact.ts`), метка задачи без названия (`src/index.ts`), имя персонажа в `lib/assets/manifest.json`.
- **Текст питомца** (`src/client/logic.ts`): `memoryLine` — русские фразы, кавычки-ёлочки, обрезка подписи 16 символов и итог «всего N».
- **Метаданные плагина**: `locale/ru.json` и `locale/en.json` (`meta.title` / `meta.description`), экспорт `./locale/*.json` в `package.json`, русский `description` как фолбэк.
- **Документация**: `README.md` — русский (главный), прежний английский перенесён в `README.en.md`, `README.zh.md` не тронут; бюджет `verify-doc-budget` для `README.md` поднят до 14500 под длину русского текста (запас > 5 %).

Механики, состояния, XP/звания-пороги, API и правила безопасности не меняются — перевод не является поведенческой веткой.

## Alternatives considered

**A: отдельный пакет/идентификатор (`whale-girl-ru`).** Позволил бы держать апстрим и перевод рядом, но потребовал бы переименовать запись патча, NAMESPACE, каталог данных, localStorage-ключи и переписать гейты `verify-config-sync`/`verify-routes-sync` — цена выше ценности сосуществования, а пользователю нужна замена, а не второй питомец. Отклонено.

**B: только словарь локали без правки hardcoded-строк.** Клиентский bundle не проходит через locale для текстов питомца (саморисуемый DOM), поэтому русский остался бы наполовину китайским. Отклонено.

**C: перевод комментариев и docs/decisions целиком.** Не влияет на пользователя, раздувает диff и ломает сверку с апстримом; документация для разработчиков остаётся как есть. Отклонено.

**D: переопределить базовые `zh`/`en` русским текстом.** Ломает контракт локали (нужны оба базовых словаря) и вводит в заблуждение при переключении языка. Отклонено.

## Consequences

- Пользовательская поверхность плагина на русском; переключение языка хоста на `en`/`zh` возвращает исходные тексты карточки настроек, тексты питомца остаются русскими (саморисуемый DOM вне locale — принятая цена варианта B).
- Тесты, проверяющие переведённые строки, обновлены (`tests/client-logic`, `tests/interact`, `tests/pet-state`, `tests/update-route` — последний теперь ждёт репозиторий форка в `package.json`); локальные гейты зелёные.
- Слияние с апстримом затрагивает только переведённые строки и `package.json` (repository/version/description/locale-exports) — конфликты локализованы.
- Установка — через `plugin_manager install_bundle` из каталога форка (локальная ссылка), поэтому строка обновления показывает «установлено из локального пути» и обновление через профиль недоступно.

Судейская проверка: частичных или полных пересечений с существующими записями нет (в дереве нет решений о локализации); настоящая запись их не заменяет.
